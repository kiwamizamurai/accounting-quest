# Security Policy

The Accounting Quest is a static browser game. It has no backend and no user accounts. Saved progress stays in your browser's `localStorage`.

## Supported versions

Only the latest version on `main`, which is what is deployed at https://kiwamizamurai.github.io/accounting-quest/, receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Include the steps to reproduce and what an attacker could do with it.

This is a hobby project maintained in spare time, so replies are best effort. You can expect an initial response within about a week.
